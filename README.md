# Southern Punjab Redeemer College (SPRC) - Official Website

Modern, responsive collegiate portal and website for Southern Punjab Redeemer College, Multan.

## Features
- **Undergraduate Academic Portfolios:** BS CS, BS IT, BS English Literature, BBA Honors, B.Ed Honors.
- **Web3Forms Cloud Storage:** Direct integration with Web3Forms API for instant admission enquiries and notifications.
- **Interactive Modals:**
  - Student & Faculty Campus Portal with authenticated dashboard view
  - Program Details & Curriculum Outline Viewer
  - Academic Calendar 2025-2026 Viewer
  - Tuition Fee Schedule & Installment Breakdown
  - Merit & Need-Based Scholarships Overview
  - Certified Forms & Downloads Center
  - Full Faculty Directory & Departmental Specializations
  - Official Collegiate Press Release / Gazette Reader
- **Direct Prospectus & Guide Downloader:** Generate and download official prospectus text.
- **Mobile Responsive:** Seamless navigation on mobile, tablet, and desktop screens with mobile drawer.

## Live Pages
- `index.html`: Main college landing page with all programs, interactive features, and embedded admissions form.
- `contact.html`: Standalone contact and inquiry page connected to Web3Forms.
